✦ Shared expense book

The best way to keep
one balance together.

A shared book for money a group puts in and spends. Everyone types the same six digits, so everyone writes to the same balance — no account, no server, nothing leaves this browser.

Open a ledger See how it works

Four steps, one page.

The whole flow is a key, a line, and a balance that everyone can see.

01

Make the book

One press makes a six-digit key. The book starts empty, with no entries and no balance.

02

Send the six

The key is the invitation. Anyone who types it opens the same list, on their own machine.

03

Write a line

A deposit or a spend is one line: date, type, category, amount. The balance moves for everyone.

04

Keep it here

Entries live in this browser. Clearing site data clears the book — there is no copy anywhere else.

Open the book.

Type the six digits someone sent you, or start a new book and pass the key on.
